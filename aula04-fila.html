Fila (Queue)

Uma coleção em que inserir acontece sempre no fim e remover acontece sempre no início. O primeiro elemento a entrar é o primeiro a sair — o princípio FIFO (First In, First Out).

Aquecimento

FIFO ou LIFO?

Na aula passada vimos a pilha (LIFO). Agora compare com situações de fila (FIFO). Clique nos cartões.

Conceito-chave

FIFO: First In, First Out

Uma fila só permite inserir no fim e remover no início. Os elementos entram "pela parte de trás" e saem "pela frente".
Remove sempre na primeira posição · Insere sempre depois da última
Formalização

Operações de uma fila

CriarInicializa a fila vazia (cabeça e cauda = None).
is_empty()Verifica se a fila não contém nenhum elemento.
inserir(e)Adiciona o elemento e ao fim da fila.
remover()Remove o elemento do início da fila; erro se estiver vazia.
Imprimir / início / tamanhoConsultam o conteúdo, o primeiro elemento e o número de elementos.
Diferente da pilha: a pilha tem nomes consagrados (push/pop). As filas não têm uma nomenclatura padrão universal — aqui usaremos inserir e remover.
Panorama

Três abordagens possíveis

📏

Vetor

Simples, mas desperdiça posições à medida que os ponteiros de início e fim avançam sem voltar.

🔗

Lista encadeada

Nossa escolha nesta aula: cabeça e cauda com custo O(1) para inserir e remover.

🔄

Matriz circular

Resolve o desperdício do vetor fazendo os índices "darem a volta" quando chegam ao fim.

Nesta aula implementaremos a fila com lista encadeada, guardando dois ponteiros — cabeca (início) e cauda (fim) — para manter O(1) nas duas operações principais.
Por que não usar só um vetor?

Fila com vetor: o espaço desperdiçado

Ao inserir e remover em um vetor, os ponteiros "primeiro" e "último" só avançam para a direita — as posições à esquerda já usadas não são reaproveitadas.

Insere(10), Insere(20), Insere(30), Remove(), Insere(40), Insere(50) — repare que a posição 0 nunca é reaproveitada

Depois de muitas operações, o vetor "anda" todo para a direita e acaba os espaços — mesmo havendo posições livres no início. É exatamente esse desperdício que a matriz circular resolve, e que a lista encadeada evita por natureza (ela só ocupa memória para os nós que realmente existem).

Laboratório

Classe No e classe Fila

Repare: o No da fila é idêntico ao No da lista encadeada simples — usa proximo, não anterior como na pilha. A Fila guarda dois ponteiros: cabeca e cauda.

class No: def __init__(self, carga=0, proximo=None): self.carga = carga self.proximo = proximo def __repr__(self): return '%s -> %s' % (self.carga, self.proximo) class Fila: def __init__(self, cabeca=None, cauda=None): self.cabeca = cabeca self.cauda = cauda def is_empty(self): return self.cabeca is None
Compare as três estruturas: Lista Encadeada e Fila usam proximo (apontam para a frente). A Pilha usa anterior (aponta para trás). O sentido do ponteiro é o que muda o comportamento.
Operações · inserir

Inserindo no fim da fila

Essa é exatamente a mesma lógica de "inserir no final" que já vimos na lista encadeada simples.

def inserir(self, elemento): novo_no = No(elemento) if self.cabeca == None: self.cabeca = self.cauda = novo_no else: self.cauda.proximo = novo_no self.cauda = novo_no

A lógica de inserir da fila corresponde a qual operação da lista encadeada simples?

Inserir no final: a cauda atual aponta para o novo nó, que se torna a nova cauda — idêntico ao que já vimos.
Operações · remover

Removendo do início da fila

A remoção sempre libera o primeiro elemento (posição 0). Se a fila ficar vazia depois da remoção, a cauda também precisa voltar a None.

def remover(self): assert self.cabeca != None, "Impossível remover elemento de fila vazia." self.cabeca = self.cabeca.proximo if self.cabeca == None: self.cauda = None
Atenção: não é possível remover um elemento do meio da fila diretamente. Para isso, seria preciso remover todos os elementos anteriores primeiro — fazer diferente quebraria as regras da fila.

Síntese

As três estruturas, lado a lado

➡️ Lista Encadeada

cabeca + prox.
Insere/remove onde o algoritmo mandar.
Sem regra de ordem fixa.

🔝 Pilha

topo + anterior.
Insere e remove sempre no topo.
LIFO — último a entrar, primeiro a sair.

🎟️ Fila

cabeca + cauda + prox.
Insere no fim, remove no início.
FIFO — primeiro a entrar, primeiro a sair.

O que muda de uma estrutura para outra não é a estrutura do nó em si — é só a regra de onde inserir e de onde remover.
Onde isso aparece de verdade

Aplicações de filas

🖨️

Impressora de rede

Documentos enviados por vários usuários são impressos na ordem em que chegaram.

📞

Central de atendimento

Chamadas e tickets de suporte são processados seguindo a ordem FIFO de chegada.

🌐

Servidor web

Requisições que chegam a um servidor costumam esperar em uma fila até serem processadas.

Curiosidade: o Python já tem uma implementação pronta de fila no módulo queue da biblioteca padrão — vale a pena explorar depois de entender como ela funciona por dentro.

Fila, em uma frase

Uma fila insere sempre no fim e remove sempre no início, seguindo o princípio FIFO — e sua implementação encadeada reaproveita o mesmo No da lista encadeada simples, só guardando também um ponteiro de cauda para manter O(1) nas duas pontas.
Para lembrar: ➡️ inserir no fim · ⬅️ remover no início · 🎟️ FIFO = primeiro a entrar, primeiro a sair · 🔗 mesmo No da lista encadeada, com cabeça E cauda guardadas.
