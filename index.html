Ative ou desative cada aula com o botão de alternância. Aulas inativas ficam esmaecidas e seu link de abertura é bloqueado — use isso para ocultar temporariamente uma aula em construção ou fora do roteiro do dia.

O estado de cada aula (ativa/inativa) fica salvo neste navegador, neste computador — se você abrir este index.html em outro navegador ou computador, todas as aulas aparecerão ativas por padrão. Para adicionar uma nova aula, edite a lista aulas no início do <script> deste arquivo: basta acrescentar um objeto { id, icon, topico, titulo, desc, href } apontando para o arquivo .html da aula, salvo na mesma pasta deste gerenciador.
