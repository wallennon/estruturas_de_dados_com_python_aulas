Lista Duplamente Encadeada

Uma extensão da lista simples: agora cada nó conhece também o nó anterior (ant), além do próximo (prox). Isso permite percorrer a lista nos dois sentidos.

⇄ ant / prox 🔁 Nos dois sentidos ⚡ Remover do fim em O(1) 🐍 Python / POO
⇄ ant ← nó → prox 🔁
ant
referência ao nó anterior
prox
referência ao próximo nó
lista circular
a cauda aponta de volta para a cabeça
⬅️ percorre do fim ao início
⚡ remover do fim agora é O(1)
🔁 sem início nem fim fixo
Aquecimento

O que muda em relação à lista simples?

A lista simples só anda para a frente. A lista dupla conhece os dois vizinhos de cada nó. Clique nos cartões.

Conceito-chave

Dois ponteiros: ant e prox

Cada nó guarda a carga e dois ponteiros: ant (nó anterior) e prox (próximo nó). A cabeça não tem anterior; a cauda não tem próximo.
ant: None
cabeça "aa"
prox ➡
➡
⬅
⬅ ant
"bb"
prox ➡
➡
⬅
⬅ ant
cauda "cc"
prox: None

Para percorrer do início ao fim, seguimos prox. Para percorrer do fim ao início, seguimos ant.

Laboratório

A classe No, agora com ant

class No: def __init__(self, carga: object = None, ant: 'No' = None, prox: 'No' = None): self.carga = carga self.prox = prox self.ant = ant def __str__(self): return str(self.carga)
Única diferença estrutural: em relação à lista simples, o nó ganhou apenas mais um atributo — ant. A classe ListaEncadeada continua com cabeca e cauda.
Operações · Inserção

Inserir no início

Três passos: (1) o prox do novo nó aponta para a cabeça atual; (2) a cabeça da lista passa a ser o novo nó; (3) o ant da antiga cabeça passa a apontar para o novo nó.

def inserir_no_inicio(self, valor: object): novo: 'No' = No(valor) if self.cabeca is None: self.cabeca = self.cauda = novo else: novo.prox = self.cabeca self.cabeca = novo novo.prox.ant = novo
Compare com a lista simples: é o mesmo algoritmo, mais uma linha — atualizar o ant do nó que deixou de ser cabeça.
Operações · Inserção

Inserir no final

(1) o ant do novo nó recebe a cauda atual; (2) o prox da cauda atual passa a apontar para o novo nó; (3) a cauda da lista passa a ser o novo nó.

def inserir_no_final(self, valor): novo: 'No' = No(valor) if self.cabeca is None: self.cabeca = self.cauda = novo else: novo.ant = self.cauda novo.ant.prox = novo self.cauda = novo

Se a lista estiver vazia, o novo elemento inserido é atribuído tanto à cabeça quanto à cauda?

Sim — em ambos os métodos de inserção, lista vazia significa cabeça = cauda = novo nó.
Operações · Remoção

Remover do início

A cabeça passa a ser seu próximo elemento, e o ant dessa nova cabeça precisa voltar a apontar para None.

def remover_do_inicio(self): if self.cabeca is None: print("Lista vazia") return if self.cabeca == self.cauda: self.cabeca = self.cauda = None else: self.cabeca = self.cabeca.prox self.cabeca.ant = None
Por que zerar o ant? O nó que virou a nova cabeça não deve mais apontar para o nó antigo — ele foi descartado e não é mais referenciado por ninguém.
Operações · Remoção

Remover do final — agora em O(1)

Diferente da lista simples, não é preciso percorrer nada: acessamos a cauda diretamente e usamos seu ant para achar o novo último nó.

def remover_do_final(self): if self.cabeca is None: print("Lista vazia") return if self.cabeca == self.cauda: self.cabeca = self.cauda = None else: self.cauda = self.cauda.ant self.cauda.prox = None

Lista simples

Remover do final: O(n) — precisa percorrer até o penúltimo nó.

Lista dupla

Remover do final: O(1) — acessa a cauda e usa o ant diretamente.

Operações · Percurso

Percorrer do fim para o início

Mesma lógica do percurso normal, mas começando pela cauda e avançando pelo ant a cada iteração.

def imprimir_invertido(self): atual: 'No' = self.cauda while atual is not None: print(atual.carga) atual = atual.ant
Compare: no percurso normal, atual = self.cabeca e avança por atual.prox. Aqui, atual = self.cauda e avança por atual.ant.

Variação

Lista circular

Na lista circular, o prox do último nó aponta de volta para a cabeça, e o ant da cabeça aponta para a cauda — formando um círculo, sem nenhum ponteiro None.
⬅ ant: cauda
cabeça "aa"
prox ➡
➡
⬅
⬅ ant
"bb"
prox ➡
➡
⬅
⬅ ant
cauda "cc"
prox: cabeça ➡

Útil para situações que "dão a volta", como uma escala de jogadores em um jogo de tabuleiro.

Cuidado especial

Percorrer uma lista circular

A mesma lógica de "percorrer até achar None" causaria um laço infinito — não existe mais nenhum ponteiro None na lista! A condição de parada precisa ser outra: percorrer até encontrar a cauda de novo.

def imprimir_lista(self): if self.cabeca is None: print("Lista vazia") return atual: 'No' = self.cabeca print(atual) while atual is not self.cauda: print(atual.prox) atual = atual.prox
Armadilha comum: usar while atual is not None em uma lista circular nunca termina — pois o prox do último nó nunca é None.
Adaptando os algoritmos

Inserir e remover na lista circular

A lógica é a mesma da lista dupla não circular — só trocamos as referências a None por referências à cabeça e à cauda.

def inserir_no_final(self, valor): novo: 'No' = No(valor) if self.cabeca is None: self.cabeca = self.cauda = novo else: novo.ant = self.cauda novo.ant.prox = novo self.cauda = novo self.cauda.prox = self.cabeca # fecha o círculo self.cabeca.ant = self.cauda # fecha o círculo
Regra geral: toda vez que a lista não-circular usaria None, a versão circular usa self.cabeca ou self.cauda para fechar o laço.

Síntese

Simples × Dupla × Circular

➡️ Simples

Cada nó só conhece o próximo.
Remover do fim: O(n).
Último prox = None.

⇄ Dupla

Cada nó conhece ant e prox.
Remover do fim: O(1).
Cabeça.ant = None, cauda.prox = None.

♾️ Circular

Igual à dupla, mas sem None.
Cauda.prox = cabeça.
Cabeça.ant = cauda.

Pergunta para decidir: precisa andar só para a frente? Lista simples. Precisa andar nos dois sentidos? Lista dupla. Precisa "dar a volta" sem fim? Lista circular.

Fechamento

Lista dupla, em uma frase

A lista duplamente encadeada adiciona um ponteiro "ant" a cada nó, permitindo percorrer em ambos os sentidos e remover do final em tempo constante — e, na variação circular, elimina os ponteiros None, fechando o laço entre cauda e cabeça.
Para lembrar: ⇄ ant + prox · ⚡ remover do fim em O(1) · ♾️ circular = sem None, cauda.prox = cabeça.
