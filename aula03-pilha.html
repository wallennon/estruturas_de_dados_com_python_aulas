Pilha (Stack)

Uma coleção em que inserir e remover só acontece em uma ponta: o topo. O último elemento a entrar é sempre o primeiro a saír — o princípio LIFO (Last In, First Out).

Aquecimento

Isso é uma pilha (LIFO)?

Pense em situações do dia a dia e da computação. Clique nos cartões.

Conceito-chave

LIFO: Last In, First Out

Uma pilha é uma coleção de dados inserida e removida sempre pela mesma ponta — o topo. O último elemento inserido é o primeiro a poder ser acessado ou removido.

Se as regras de "só manipular pelo topo" forem desrespeitadas, a estrutura deixa de ser uma pilha.

Pergunta de verificação: em uma pilha de blusas, para pegar a blusa de baixo, o que é preciso fazer primeiro? Retirar todas as de cima — você nunca "pula" direto para o meio ou para o fundo.
Formalização

A pilha como TAD (ADT)

Formalmente, uma pilha S é um Tipo Abstrato de Dados que suporta estas operações:

push(e)Adiciona o elemento e ao topo da pilha S.
pop()Remove e retorna o elemento do topo de S; erro se S estiver vazia.
top()Retorna uma referência ao elemento do topo, sem removê-lo; erro se S estiver vazia.
is_empty()Retorna True se a pilha S não contém nenhum elemento.
__len__(S)Retorna o número de elementos em S (em Python, via método especial).

Laboratório

Classe No e classe Pilha

Assim como na lista encadeada, cada elemento é um No. A diferença é só conceitual: em vez de prox, o nó guarda anterior; e em vez de cabeca, a estrutura guarda topo.

class No: def __init__(self, carga=0, anterior=None): self.carga = carga self.anterior = anterior def __repr__(self): return '%s -> %s' % (self.carga, self.anterior) class Pilha: def __init__(self): self.topo = None def is_empty(self): return self.topo is None
Compare: lista encadeada simples → cabeca + prox. Pilha → topo + anterior. O algoritmo é quase idêntico!
Operações · push

Inserindo elementos no topo

Todo novo elemento é sempre inserido no topo — a mesma lógica de inserir no início de uma lista encadeada. O novo nó aponta (anterior) para o topo atual, e então se torna o novo topo.

def push(self, elemento): no = No(elemento) no.anterior = self.topo self.topo = no

A lógica de push é parecida com qual operação da lista encadeada simples?

Inserir no início: o novo nó aponta para o antigo topo/cabeça, e passa a ser o novo topo/cabeça.
Operações · pop

Removendo o elemento do topo

A remoção acontece sempre no topo: avançamos a referência de topo para o nó anterior a ele, descartando o antigo topo.

def pop(self): assert self.topo != None, "Impossível remover elemento de pilha vazia." self.topo = self.topo.anterior
Por que o assert? Tentar remover (fazer pop) de uma pilha vazia é um erro — por definição, não existe elemento algum para remover. O assert interrompe a execução com uma mensagem clara nesse caso.
Operações · consulta

__repr__, consultar o topo e __len__

Para imprimir a pilha, implementamos __repr__. Para saber o tamanho, percorremos a partir do topo contando os nós — igual ao percurso que já fizemos na lista encadeada.

def __repr__(self): return "[" + str(self.topo) + "]" def __len__(self): atual = self.topo c = 0 while atual is not None: c += 1 atual = atual.anterior return c
Acessar o topo diretamente: não precisa de método especial — basta ler o atributo pilha.topo do objeto.

Aplicações de pilhas

📞

Pilha de chamadas

O sistema operacional usa uma pilha para controlar qual função retorna para qual, na ordem inversa das chamadas.

↩️

Desfazer (Ctrl+Z)

Cada ação é empilhada; desfazer é um pop que volta exatamente para a ação anterior.

🧮

Parênteses balanceados

Validar expressões como ((a+b)*c): empilha ao abrir, desempilha ao fechar.

Desafio extra: implemente eh_balanceada(expressao) — percorra a string empilhando cada ( e removendo (pop) a cada ) encontrado. Se a pilha terminar vazia, a expressão está balanceada.
Síntese

As duas implementações são quase iguais

➡️ Lista Encadeada Simples

cabeca referencia o primeiro nó.
Cada nó aponta para o prox.
Inserir/remover no início: O(1).

🔝 Pilha

topo referencia o último nó inserido.
Cada nó aponta para o anterior.
push/pop no topo: O(1).

A mudança é só conceitual: o algoritmo de "inserir/remover no início" de uma lista encadeada é exatamente o algoritmo de push/pop de uma pilha.
Síntese

Custo das operações

push(e)O(1) — só cria o nó e atualiza o topo
pop()O(1) — só avança o topo para o anterior
top() / is_empty()O(1) — apenas consultam o atributo topo
__len__()O(n) do jeito mostrado — mas pode virar O(1) guardando um contador atualizado a cada push/pop

Fechamento

Pilha, em uma frase

Uma pilha só permite inserir e remover pelo topo, seguindo o princípio LIFO — e sua implementação encadeada é praticamente idêntica à lista encadeada simples, só trocando "cabeça" por "topo" e "próximo" por "anterior".
Para lembrar: 📥 push insere no topo · 📤 pop remove do topo · 🔝 só o topo é acessível · ↩️ LIFO = último a entrar, primeiro a sair.
